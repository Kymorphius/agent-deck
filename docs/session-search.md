# 会话搜索范围

<!-- matrix/hardened: retain local/remote identity separately from search scope and reveal behavior. -->
这三种入口搜索当前 profile 已管理的本机会话，以及列表已加载的远端会话快照。匹配标题、分组、项目路径和工具，支持 `agent deck` 匹配 `agent-deck`、`adk` 等顺序缩写。搜索本身不额外发起远程请求；远端列表刷新后，搜索候选同步更新。

| 快捷键 | 搜索范围 | 回车定位 |
| --- | --- | --- |
| `/` | 全部本机与已加载远端会话，包含归档会话 | 清除状态、时间、置顶、最近和分组范围等视图筛选，再展开目标分组并定位 |
| `Alt+?`，即 `Alt+Shift+/` | 当前视图及其筛选条件下的本机与远端会话 | 保持当前视图和筛选，展开并定位其中的结果 |
| `Alt+/` | 当前选中分组的直属会话；远端分组同时限定设备 | 清除挡住目标的视图筛选，再展开并定位该组中的结果 |

macOS 使用 `Option` 代替 `Alt`，兼容普通 Option 模式产生的 `¿` 和 `÷`。快捷键在会话列表中生效。当前分组由光标选中的分组、会话或窗口确定；没有可确定的具体分组时，`Alt+/` 会说明原因并打开全部会话搜索。

搜索框底部标明全部会话、当前视图或当前分组的范围，远端结果显示设备名称。同名或同 ID 的会话按本机或“远端设备＋完整 ID”区分。当前视图的集合包含折叠组里的匹配会话，不限于屏幕上当前露出的行；状态、归档、时间、置顶、最近交互和分组范围会组合生效。后台刷新继续应用打开时的范围，保留关键词和仍存在的选中会话。

打开搜索和按 `Esc` 取消不会清除主列表筛选。回车只定位结果，不会启动或连接会话；定位后再按普通打开键，沿用列表的打开流程。选择全部搜索或分组搜索的结果后才调整视图；归档结果切换到归档列表，保留会话的归档状态。远端结果会展开对应设备和全部分组祖先。搜索期间被删除、移出分组或不再符合当前视图的结果会提示重新搜索，不会跳到相邻条目或另一设备的同 ID 会话。

`Alt+?` 可通过 `[hotkeys].view_search` 重绑，空字符串表示禁用：

```toml
[hotkeys]
view_search = "alt+?"
```

`Alt+S` 是单独的[分组名称搜索](group-search.md)。`G` 和搜索中的 `Tab` 打开 Recall 全文搜索，`Alt+R` 限定已管理会话的全文内容；Recall 中已管理结果的定位同样会清除挡住目标的视图筛选。Recall 是独立的数据源，当前 TUI 查询本机索引，不因会话标题搜索加入 remote 而变为远程全文联邦查询。
